# Cloud Native Provence (CNP) - Banner Design Guide

## Project Overview
Professional event banners created for Cloud Native Provence community using Python (PIL/Pillow) with Provence Blue (#356cc8) as the primary brand color.

## Brand Colors
- **Provence Blue (Primary):** #356cc8 | RGB(53, 108, 200)
- **Dark Blue (Accent):** #1e3a7a | RGB(30, 58, 122)
- **White (Secondary):** #ffffff | RGB(255, 255, 255)
- **Light Background:** #f0f4fa | RGB(240, 244, 250)

## Banner Specifications
- **Dimensions:** 1920 x 600 pixels
- **Format:** PNG (high-quality, 95% compression)
- **Use Case:** Social media, website headers, event announcements
- **Color Space:** RGB

## Typography
### Fonts Used

   - Characteristics: Geometric, clean, contemporary

- **Secondary Title:** 56-80px
- **Subtitle:** 44-52px
- **Body Text:** 40-48px

## Design Principles Applied

### 1. Visual Hierarchy
- Large, bold typography for main messaging
- Smaller, regular fonts for supporting text
- Strategic use of white space
- Color contrast for emphasis

### 2. Modern Tech Aesthetic
- Clean lines and geometric shapes
- Subtle gradients and transparency
- Minimal but purposeful decoration
- Professional, trustworthy appearance

### 3. Brand Consistency
- Provence Blue (#356cc8) as primary accent
- White and light backgrounds for clarity
- Logo prominently featured
- Consistent typography across banners

### 4. Accessibility
- High contrast ratios (white on blue, blue on white)
- Clear, readable fonts
- Sufficient spacing between elements
- No small text or hard-to-read combinations

## Customization Guidelines

If you need to customize these banners:

1. **Text Changes:** Modify the text while maintaining font sizes and positioning
2. **Colors:** Update RGB values in the color definitions (maintain contrast)
3. **Logo:** The helm logo can be modified by adjusting radius, spoke count, or element proportions
4. **Backgrounds:** Gradients can be adjusted by changing the ratio calculations
5. **Sizing:** Fonts should scale proportionally with canvas size
